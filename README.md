# Systems Engineering Labs

Hands-on engineering labs focused on Linux, networking, containers, system internals, and troubleshooting.

## About

This repository documents my practical learning journey toward Cloud, DevOps, Platform Engineering, and Site Reliability Engineering.

The focus is not simply on using tools, but on understanding how systems work, investigating failures, and reinforcing knowledge through repeated experiments.

## Learning Approach

Each topic follows six steps:

1. Understand the concepts and terminology.
2. Build a working environment.
3. Observe system behavior.
4. Introduce and troubleshoot failures.
5. Repeat exercises independently.
6. Document findings and revisit concepts in future labs.

## Tools & Environment

- macOS (Apple Silicon)
- Ubuntu Server ARM64 (UTM)
- Linux CLI and networking utilities
- Docker and Kubernetes
- Bash, Python, and Git

Tools will be introduced progressively as needed.

## Goal

Develop strong fundamentals in Linux and networking, understand the internals of modern infrastructure, and build practical troubleshooting skills applicable to real-world cloud-native systems.
